# Security policy

## Reporting

Do not open public issues containing vulnerabilities, credentials, property ownership details, tenant data or financial records. Use GitHub private security-advisory reporting.

## Data handling

This repository is public. Only fictional demo data and public-source configuration may be committed. Private workbooks, geocode caches, title boundaries, underwriting, leases, tenants, debt, valuations and trained private-data models must remain outside Git.

## Supported version

Security fixes target the latest main branch.
