# Portfolio data assessment

The supplied workbook is a property catalogue assembled from rental, sale, mall, storage, hotel and serviced-residence lists. It is useful for identifying assets, locations, segments, brands and selected asking rents or unit sizes. It is not an investment underwriting dataset.

## Loaded data

- 260 deduplicated properties across Singapore and international markets.
- 177 Singapore properties within the URA model jurisdiction.
- 83 international properties retained but excluded from Singapore zoning calculations.

## Missing decision inputs

Verified title lot and parcel geometry, ownership share, tenure, site area, existing GFA/NLA, occupancy, passing rent, NOI, lease expiry, tenant concentration, appraisal, debt, capex, development pipeline, planning history and transaction evidence.

Until these are provided, all financial recommendations remain provisional proxy runs and are labelled accordingly in the API and user interface.
