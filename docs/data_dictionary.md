# Data dictionary

## Portfolio source fields

Asset ID, property name, country, jurisdiction, segments, source address, minimum advertised unit size, advertised monthly rent, source sheets and source rows.

## Geospatial fields

OneMap latitude/longitude, postal code, geocoded address, URA spatial matches, land-use description, GPR text/numeric value, open-layer vintage, current-plan verification flag and match warning.

## Capacity outputs

Statutory GFA, geometric GFA, physical GFA, de facto GFA, expected approved GFA, economic GFA, unused economic GFA, buildable footprint, height-based storeys, binding constraints, marginal sensitivities, residual option value and P10/P50/P90 attainable GFA.

## Economic outputs

Proxy current value, proxy NOI, DCF value, incremental action NPV, capex, financing cost, disruption cost, execution-failure cost, probability of loss, VaR, CVaR and execution time.

Every proxy field carries a source-quality label and verification requirement.
