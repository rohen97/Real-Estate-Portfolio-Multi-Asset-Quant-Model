# Repository data policy

The GitHub repository is public. Only fictional examples, public-source configuration and code may be committed.

## Excluded

Company asset registers, rent rolls, tenant identities, title documents, geocode caches, valuations, NOI, debt, capex, planning submissions, decision logs and private model artifacts.

## Included

Fictional ten-asset demo fixtures, the frozen legacy formula specification, transformation-zone screening configuration, schemas and validation examples.

## Local private mode

Place private inputs under ignored folders such as data/input, data/observed and data/title_boundaries. Generated outputs remain ignored.
